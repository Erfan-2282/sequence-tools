# Sequence Tools

A simple Python project for working with mathematical sequences and patterns.

## Features

This version can detect and work with several types of sequences:

* Arithmetic sequences
* Geometric sequences
* Quadratic sequences
* Triangular sequences
* Fibonacci sequences
* Prime number sequences

For supported sequence types, the program can:

* Find the nth term
* Display the formula of the sequence
* Calculate the sum of the first n terms

## Requirements

* Python 3.x
* No external packages are required.

## Usage

Run the Python file and enter the numbers of your sequence in order.

The sequence must contain at least three numbers. When you are finished entering the sequence, type:

```text
finish
```

The program will detect the type of sequence and let you choose an operation.
